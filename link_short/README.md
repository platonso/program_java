# Сокращатель ссылок

Консольный сервис создаёт короткие ссылки, открывает исходный адрес в браузере, ограничивает число переходов и автоматически удаляет истёкшие ссылки.

## Возможности

- уникальный код для каждой созданной ссылки, включая одинаковые URL у разных пользователей;
- UUID пользователя без регистрации: владелец один может просматривать, менять лимит и удалять только свои ссылки;
- лимит переходов с блокировкой после его исчерпания;
- TTL, задаваемый приложением, и фоновая очистка просроченных ссылок;
- открытие исходных URL в браузере.

Данные хранятся в памяти процесса, т.е. после выхода из программы пользователи и ссылки удаляются.

## Требования и запуск

Java 17+ и Maven 3.9+.

```bash
mvn exec:java
```

## Команды

При первом `create` пользователь создаётся автоматически. Напечатанный UUID сохраните: он нужен, чтобы вернуться к своим ссылкам в рамках запущенной программы. При желании пользователя можно создать заранее командой `new-user`.

`open` засчитывает переход до открытия браузера. Когда лимит уже исчерпан, браузер не запускается и выводится уведомление. Просроченная ссылка удаляется при фоновом проходе очистки, выводе списка или попытке перехода.

## Конфигурация

Все ключевые параметры находятся в [application.properties](src/main/resources/application.properties): адрес коротких ссылок, обычный и максимальный лимит, TTL и период очистки. В частности, `ttl-hours` задаётся только программой команда CLI не позволяет пользователю продлить TTL.

## Архитектура

- `domain` - правила переходов, лимитов и срока жизни;
- `service` - сценарии создания, перехода и авторизации владельца;
- `repository` - контракт хранения и потокобезопасная in-memory реализация;
- `cli` - команды пользователя и открытие браузера;
- `config` - загрузка проверяемых параметров.

## Тестирование

В `LinkServiceTest` 19 unit/integration-подобных сценариев: уникальность, URL-валидация, лимиты, доступ владельца, мультипользовательский режим, TTL и очистка. Запуск: `mvn test`.

```bash
mvn test
```
